# 产品路线图

## v0 — 匿名会话跑通业务

目标：

- 匿名会话
- 支付/充值
- 上传文件
- 异步 OCR API
- DOCX 下载

核心原则：

- 先跑通业务闭环
- 不让账号体系阻塞上线

## v1 — 商用首版

新增：

- 更稳定的支付与补偿机制
- 任务列表与状态页
- 下载授权与时效控制
- 基础运营指标与错误分类

## v1.1 — 手机号验证码登录

新增：

- 手机号验证码登录
- 匿名会话与账户绑定

## v1.2+ — 微信能力绑定

新增：

- 公众号导流增强
